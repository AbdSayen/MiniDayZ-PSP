Locals: Row, anotherX, anotherX2 (init -1)
For Row = 0 .. Map_size_X-1:
  Reset anotherX/anotherX2
  For each column on row: Array uid 150 At(col, Row) in {9,6,11,15}
    When value == 15: first -> anotherX, second -> anotherX2
  When anotherX/anotherX2 valid and anotherX2 > anotherX:
    If At(anotherX, Row) == 0 -> SetAt(anotherX, Row, 13)
