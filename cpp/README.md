# Mini DAYZ C++ engine

Native rewrite of Bohemia Interactive **Mini DAYZ 1.4.1** (Construct 2 export in `../original_docs/`).

This is **not** a JS wrapper. Gameplay systems are implemented in C++ under `src/`, with balance constants auto-extracted into `include/mdaz/balance_globals.hpp`.
