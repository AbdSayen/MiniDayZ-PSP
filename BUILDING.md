# Building Mini DAYZ C++

Last verified desktop build: **2026-10-17** (MinGW + vendored SDL2).  
PSP EBOOT: **not verified** on this machine — see `KNOWN_ISSUES.md`.

## Prerequisites (desktop host — verified path on this project)

- CMake ≥ 3.16
- C++11 compiler (MinGW g++ / MSVC / Clang)
- Optional: SDL2 (for windowed host). Without SDL2 the desktop binary uses a null/console platform.

### Windows (MinGW + bundled SDL2)

SDL2 MinGW devel is vendored under `cpp/third_party/SDL2-2.30.9/` (downloaded once).

```bat
cd cpp
set SDL=C:\Users\abdur\Desktop\MiniDayZ\cpp\third_party\SDL2-2.30.9\x86_64-w64-mingw32
cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=%SDL%
cmake --build build -j
copy /Y third_party\SDL2-2.30.9\x86_64-w64-mingw32\bin\SDL2.dll build\SDL2.dll
cd build
mdaz_tests.exe
minidayz_desktop.exe
```

Data files are copied next to the binaries from `cpp/data/` (items.json, bunker_json).  
`SDL2.dll` must sit next to `minidayz_desktop.exe`.

### Controls (PSP-first, same layout on desktop) — 2026-10-19

The UI is laid out for the PSP screen (logical 480×272, 6 px safe margin, 5×7 font at 1 px,
6 px advance, 1 px shadow). There is no mouse/touch UI: the virtual stick and tap buttons are
gone, every action has a PSP button and an on-screen hint (bottom hint bar). Desktop shows PSP
glyphs by default; `minidayz_desktop.exe --keys` shows keyboard caps instead.

| PSP | Desktop | Gameplay |
|-----|---------|----------|
| Analog / D-Pad | WASD / arrows | Move |
| × Cross | Z / Space | Attack / shoot |
| ○ Circle | E | Interact (loot / car / bunker / chop / search) |
| △ Triangle | C | Use equipped item |
| □ Square | R / V | Reload (magazine) |
| R (hold) | Shift | Run |
| L (hold) | Ctrl | Crouch |
| Select | Tab | Inventory open/close |
| Start | Esc / P | Pause menu |
| L + ←/→ | Q / X, 1–8 | Hotbar slot |
| R + × | F | Throw |
| R + ○ | G | Drop equipped |
| R + △ | T | Torch / campfire |
| R + □ | B | Craft menu |
| L + Start | F5 | Quick save |
| L + Select | F9 | Quick load |

Menus (main, pause, craft, inventory): D-Pad moves focus (auto-repeat 0.32 s / 0.11 s),
× (Enter/Space) confirms, ○ (Esc/E/Backspace) goes back.

- **Main menu:** NEW GAME · CONTINUE (disabled without `save.mdaz`; builds the world first) ·
  DIFFICULTY (←/→) · CONTROLS · EXIT. Desktop 1/2/3 still pick difficulty.
- **Pause:** RESUME · SAVE GAME · LOAD GAME · CANCEL TASK · CONTROLS · MAIN MENU. Start / ○ resume.
- **Inventory:** 8-column bag grid (row 1 = hotbar) + worn containers (pants / jacket / vest /
  backpack). × use / wear (container slot: take), △ move to hand (hotbar slot), □ drop, ○ / Select close.
  The world keeps running while the inventory is open (C2 does not pause on `Inventory_opened`).
- **Craft:** list of C2 recipes, green = possible; × craft (toast CRAFTED / MISSING ITEMS / NEED A FIRE).

### Scripted screenshot run

`minidayz_desktop.exe --shots <dir>` plays a fixed input script and writes BMPs:
`menu`(50) `spawn`(180) `run_a..d` `walk`(430) `bag`(510, inventory with D-pad focus moved)
`craft`(545) `explore1`(900) `explore2`(1390) `pause`(1530, focus on SAVE) `controls`(1570).
Time is fixed at 60 fps, so the run is deterministic apart from the world seed.

```bat
node tools/analyze_c2.js original_docs/data.js

node tools/extract_bullet_iv0.js

node tools/extract_layout_sprites.js Menu cpp/data/menu_sprites.txt Buildings_shadows,Zeds,Buildings_base,Buildings,bg_build

```

`world_tilemaps.txt`, `menu_tilemaps.txt` and `menu_sprites.txt` in `cpp/data/` are generated by the last three tools (the Menu tilemap dump is renamed to `menu_tilemaps.txt`).

Outputs land in `cpp/docs_gen/` and `cpp/include/mdaz/balance_globals.hpp`.

## PSP

`EBOOT.PBP` lives at `cpp/platform/psp/EBOOT.PBP` (built with WSL + [pspdev](https://github.com/pspdev/pspdev)).

Rebuild:

```sh
# WSL
export PSPDEV=/root/pspdev   # or $HOME/pspdev
export PATH="$PSPDEV/bin:$PATH"
cd /mnt/c/Users/abdur/Desktop/MiniDayZ/cpp/platform/psp
make clean && make
```

**Slim deploy (required):** all C2 PNGs are packed into **one** `data/sprites.pak` (not 1000+ loose files beside EBOOT).

```powershell
powershell -File tools/pack_psp_deploy.ps1
# → cpp/platform/psp/deploy/MINIDAYZ/  (EBOOT + data + sprites.pak)
```

Copy `deploy/MINIDAYZ` to `ms0:/PSP/GAME/` or PPSSPP memstick `PSP/GAME/`.

PSP blits sprites from `sprites.pak` onto the soft framebuffer (same assets as PC). See `KNOWN_ISSUES.md`.
